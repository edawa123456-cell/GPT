# Towing Website

Clean Next.js project created to deploy directly to Vercel.

## Important
The `app` folder and `package.json` are at the project root, so Vercel should detect the site correctly.

## Deploy
1. Extract this ZIP.
2. Upload the CONTENTS directly to the root of a GitHub repository.
3. Import that repository into Vercel.
4. Framework preset: Next.js.
5. Root Directory: `./`
6. Deploy.

No environment variables are required for this preview version.
